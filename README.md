# YouTube-Music-Streaming-Performance-Dashboard
YouTube-Music-Streaming-Performance-Analysis

This project presents an analysis of music streaming performance, focusing on artists, tracks, albums, playlist reach, likes, and audience engagement.

🔍 Overview

The YouTube Music Streaming Performance Dashboard provides an interactive view of music content performance and audience engagement.

The dashboard analyzes:

* Artist performance
* Track popularity
* Album performance
* Playlist reach
* Track likes
* Audience engagement
* Content performance

🎯 Objectives

* Identify top-performing artists.
* Determine the most-played tracks.
* Analyze album performance.
* Measure playlist reach.
* Examine audience engagement.
* Identify popular content for targeted promotion.

❓ Business Questions

* Which artist has the highest playlist reach?
* Which track is most played?
* Which album performs best?
* Which content attracts the most audience engagement?
* Which artists and tracks should receive more promotional attention?

📚 Dataset Description

Dataset: YouTube Music streaming performance data
Data Type: Music streaming and audience engagement data

Key Fields:

* Artist
* Track
* Album
* Playlist Reach
* Track Likes
* Engagement
* Content attributes

🛠️ Tools & Technologies Used

* Microsoft Excel
* PivotTables
* Excel Charts
* KPI Analysis
* Data Visualization
* Data Cleaning
* Data Storytelling

🧹 Data Cleaning and Preparation

* Cleaned artist and track names.
* Standardized album information.
* Checked numerical engagement metrics.
* Organized streaming and playlist metrics.
* Prepared data for dashboard analysis.

📈 Key Trends Discovered

* The Weeknd recorded the highest playlist reach at 19.22%.
* “Peru” was the most-played track at 23.13%.
* The Highlights (Deluxe) was the leading album.
* A small number of artists and tracks dominated audience engagement.

📊 Dashboard Development

The dashboard presents:

* Top artists
* Most-played tracks
* Album performance
* Playlist reach
* Track likes
* Audience engagement

💡 Recommendations

* Promote high-performing artists and tracks.
* Create targeted playlists around popular music.
* Use audience preferences to guide content promotion.
* Analyze listener behavior to improve music recommendations.

Conclusion

The dashboard demonstrates how streaming data can be used to understand artist popularity, track performance, playlist reach, and audience engagement.
